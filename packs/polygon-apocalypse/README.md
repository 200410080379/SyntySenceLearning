# POLYGON Apocalypse 场景训练

首批学习使用 POLYGON Apocalypse Pack v1.20.0 的 UE 5.3 资源，在 UE 5.8.2 中完成原场景研究和地面验证。资源引用根目录为 `/Game/PolygonApocalypse`，原场景为 `/Game/PolygonApocalypse/Maps/Demo`。

| 训练 | 目标 | 已有证据 |
| --- | --- | --- |
| [01 原包地面拼接](studies/01-ground-assembly/README.md) | 认识角枢轴、道路与人行道接口、转角及入口 | 30 个学习实例、7 张截图、截面分析与历史保存重开记录 |
| [02 城市地面验证](studies/02-city-ground/README.md) | 将接口规律用于独立的 80×80 米城市地面 | 256 块布局、480 条接缝历史实测、6 张截图与问题修正记录 |
| [03 扩大街区](studies/03-expanded-neighborhood/README.md) | 将地面扩大到 200×160 米，以错位 T 字路口连接不同区域 | 1,280 块布局、2,488 条接缝实测、保存重开只读核对；加油站、饭店、旅馆等区域的地面预留 |
| [04 建筑装配与摆放](studies/04-building-placement/README.md) | 研究原包主体、玻璃、门和附件，按区域放入第三课地图 | 10 套装配配方、14 组装配、94 个部件；源 Demo 观察、入口高度与前场修正记录 |
| [05 末日小城](studies/05-aftermath-town/README.md) | 从真实节点学习局部组合、地表旧化和自然侵入，搭建独立小城 | 5,053 个模型实例、214 种模型、184 个贴花和 11 个机位；主图和独立完整复现副本保存重开、实例核对零错误 |

建议按顺序学习。第一课的入口配方反映原 Demo 的实际组合；第二课进一步发现它不能直接嵌入所选普通平边网格，因此使用与该网格兼容的 `Dip_01`。原场景摆法和自创布局的接口要求需要分别验证。

第三课在相同接口基础上安排主街、短支路、不等长街块、入口和前后场。第四课在这张地图中加入加油站、饭店、旅馆、修车店和商铺，重点核对建筑装配、朝向与前场，保留第三课地面配方。碰撞、导航、车辆转弯和可交互室内仍需后续研究；沟渠、高架等特色区域可在实际需要时增加独立训练。

第五课保留上述参考，在独立 `AftermathTown` 地图中加入车辆、城市设施、功能道具组、局部土层、植物和贴花，并用外围道路、林缘与山体补足城市边界。其方法先读取源地图和 Blueprint 节点的引用、变换、材质及缺失依赖，再检查几何与画面；不会仅凭截图判断组件关系。该课额外研究 Woodland 示例的氛围与屋顶搭配，依赖版本和路径别名见课内清单。主图和独立完整复现已保存重开并完成实例核对，有限碰撞检查及其接缝未命中也有记录。当前仍是美术训练场景，部分空地与模块排列需要继续深化；性能、导航、玩法和打包发布尚未验收。 饭店西侧与旅馆东侧另增 158 个模型实例和 12 个贴花，形成连续植被带，原有 456 个内部自然侵入实例保留。

后续本资源包训练继续放在此目录的 `studies/` 下；其他 Synty 资源包创建自己的 `packs/<pack-id>`。不同资源包的尺寸、材质和枢轴可能不同，不能把这里的 5 米网格当作全系列通则。

复现前需在本地 UE5 工程中安装已有授权的资源，并启用 Python 与 Editor Scripting Utilities。参见[仓库准备步骤](../../README.md#在自己的-ue-工程复现)和[统一工作流](../../docs/WORKFLOW.md)。原始资产、源 Demo 和完整测量几何不包含在仓库中。
